# i6eal-open-ai-data-api
A free, no-authentication open-data REST API from i6eal (a German AI studio) exposing 16 AI-related datasets and monitors for Germany and the EU as static JSON/CSV/JSON-LD/Atom files served over HTTPS/CDN. Backed by a live OpenAPI 3.0.3 contract and a DCAT-AP JSON-LD catalogue.
